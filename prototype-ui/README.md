# PortfolioHub UI prototype

Prototipo usa-e-getta per verificare la direzione scelta: **app pulita e moderna, dark-first, sidebar richiudibile, impostazione Bootstrap-like e gradienti blu controllati.**

Verdetto del 31 luglio 2026: direzione visiva approvata. Il prototipo resta come riferimento temporaneo fino all'assorbimento nella UI Angular di produzione, poi deve essere rimosso.

Avvio:

```bash
python3 -m http.server 4173 --directory prototype-ui
```

Aprire `http://localhost:4173/`. Il prototipo usa dati in memoria e non rappresenta l'implementazione Angular definitiva. Sono interattivi sidebar, tema, navigazione, creazione progetto e scelta fra link cliente e invito collaboratore.
